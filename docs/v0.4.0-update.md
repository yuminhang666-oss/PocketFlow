# PocketFlow 0.4.0

基线：远程 main `171194f30b3873f93edf090f29773e9a099e16ad`（0.3.4）。本轮由主控在独立 `integration/v0.4.0-design` 分支集成，用户已明确授权执行 2026-10-26 设计交付、上传 GitHub 并发布可安装版本。保留独立 PR、CI 和合并记录，不直接推送 main。

## 最终行为

用户在执行中补充：首页仅在用户设置了小目标时显示目标区；没有目标时整块隐藏，不显示空态或新建占位。新建和管理入口保留在“我的 → 小目标”。此要求优先于原设计包中的首页空态建议。

- 总览固定当前自然月，今起日均参考为最大层级；删除常驻均分解释，余额右侧保留调整预算。目标摘要与增加进度位于最近账单之前；四宫格连接记账日历、周期计划、周报月报和我的。“本月账单”重置既有账单标签的月份及筛选。
- 首页、账单查看月份、统计查看月份、报告期间及预算编辑月份分别管理。普通新增始终取调用时的今天；只有显式日历补记带入历史日期；编辑保留原日期；连续保存保留本批次日期。
- 账单默认列表，主动切换到同一模块的日历；日历共享搜索、类型、分类、金额及日期范围。选日直接展示记录，支持滑动和箭头切月、短月日期夹取、回今天、明确补记及主动零支出。零支出资格依据完整快照，不能被筛选隐藏的支出绕过。
- 记账保留数字键盘、连续保存和撤销；标题、发生日期和收支保存文案清楚。模板放入更多；套用模板确认覆盖，保留发生日期；不可用分类要求重新选择。窄屏只显示一行稳定快捷根类，其余通过完整分类搜索访问。
- 目标增加只修改目标登记；更正累计值独立标明，更新不重排原目标顺序。
- 周期计划分待处理与规则管理，到期项优先，未来仅展示七天内的预告；其他月份逾期数量与查看全部可达。确认面板提供实际金额和实际日期，事务内写账和处理期，同一期重复确认返回原账目。收入不增加预算，跳过及撤回不产生账目。
- 同一报告中心提供周报/月报、期间选择、相邻期间切换和本期截至日。指标、每日双系列趋势、真实比例分类排行及简短回顾均来自一个范围快照。逐日、分类和最大支出可以核对实际账目；进行中期间仅对比上期同等天数。旧周报范围与历史月报保留。
- 收入红 `#D74747`，支出绿 `#168454`，交互蓝 `#3563E9`。分类身份色按设计色表，子类继承根类；选中依然有边框和勾选。根类可选预设颜色，改名、排序、归档、重启及备份不随机变化。深色提高明度，金额零值中性。

## 合同与兼容

合同增量 v3.2.0；Flutter 依赖及锁不变。数据库仍 schema4，JSON3，recovery3，原包名 `cn.pocketflow` 和既有升级签名不变。版本 `0.4.0+11`。

- `PersonalProfile.categoryColors` 是可选的根分类 ID → ARGB 整数映射，旧数据缺省空；同一快照投影到 `Category.colorValue`。保存类别和颜色在一个事务内完成，复用个人设置 JSON，不改历史分类 ID 或财务表结构。公开备份和恢复点均保留颜色映射。
- `PlanningPort.confirm` 增加可选 `actualLocalDate`，旧调用沿用计划到期日。计划到期日与实际发生日期均不得在未来。处理期的 `actualLocalDate` 在既有 `plan_settings` 以 `actualDate:<ruleId>:<period>` 存储，在同一事务内读取/写入，不更改历史规则。
- `RecurringOccurrence.actualLocalDate` 为可选备份字段；旧档案仍以规则到期日校验，新档案核对实际日期与关联账单一致。恢复、内部恢复点及重新打开后仍可判定同一期已确认。含跨日确认的新备份应使用 0.4.0 或后续兼容版恢复，旧版严格关联校验可能拒绝该档案；不支持降级写回。
- 不增加地点、商户、后台自动入账、账号、网络账本或新依赖。不更改真实金额、账单日期或分类关联。演示数据仅由显式工具写入隔离模拟器，不进入应用安装包或正式账本。
