# PocketFlow 0.4.2 更新说明

日期：2026-10-28。发布状态以 [GitHub Release](https://github.com/yuminhang666-oss/PocketFlow/releases/tag/v0.4.2) 实际记录为准。版本 `0.4.2+13`，基于远程main `dd71ccbe00bb9377a02658ee8114d7bdcb86ccc4`（0.4.1+12）。

## 本轮改进

1. 报告重复点击已选中的周报/月报保持当前期间。切换类型沿用正在查看的日期；较早月报超出周报保留窗口时切回本周。周报按钮改为“切换到月报”，期间入口显示“选择月份/选择日期”。取消选月不改变期间。按钮同行排布，减少独占一行。
2. 账单日期筛选统一在无时区的日历容器内比较上下界，再以本地年月日交给系统选择器。未来月份的日期筛选禁用，避免无响应的可点入口。
3. 记账备注显示“备注（选填）”，窄屏可换行；备注摘要保留。细分类溢出时显示前后滚动按钮，可滑动或逐段点击到末项；能放下时隐藏按钮。完整分类入口触控至少48dp，不改变目录与排序。
4. 保存错误移到金额附近，存储失败明确说明“未保存，内容仍在”；不自动重试。普通保存和连续保存反馈包含收支类型、金额、分类及日期，成功反馈仍在持久化完成后触发。保留既有重复提交保护、草稿确认和条件撤销。
5. 账单筛选变化增加读屏可感知的条件数量及结果笔数；趋势图提供金额摘要与逐日明细路径。报告页内定位和分类滚动遵循系统减少动画设置。全部新增文案包含简体、繁体和英文。
6. 报告页面仅接收自然周锚点 `initialStart`，移除未使用的 `initialEnd`，同步主控提醒入口及调用测试。没有增加任意日期报告。

## 兼容与边界

财务合同3.2.0、数据库schema4、JSON3、recovery3不变；金额仍为整数分。没有新增依赖、账户、自动入账或同步。预算、目标、周期算法、存储路径、分类身份、用户原文和签名身份不变。

用户已追加授权本版经PR集成并发布安装包与源码，完成状态及下载附件以GitHub Release为准。验证记录保留未完成的真机和读屏项目；不将发布成功当作这些设备验收已经通过。
