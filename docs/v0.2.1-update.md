# PocketFlow 0.2.1：手动更新入口

版本0.2.1+4；主控独立integration/v0.2.1-updates分支，依赖PR #6候选081d6b4，公共main仍为8b224de，尚未合并。

在“我的”增加“检查更新”，进入页面读取本机版本，点击按钮才联网查询。显示新版内容和安装包大小，下载按钮交由浏览器下载并由Android系统确认覆盖安装。无启动/前台自动检查、后台任务、首页提醒或自动安装。

旧0.1.1/0.2.0没有该入口，需先手动覆盖安装一次0.2.1。原包名cn.pocketflow、签名和数据库位置保持，schema3、JSON2、财务合同候选2.0.0及依赖锁不变；新更新传输合同独立为v1。没有上传真实账单或签名私钥。
