# 0.4.1 三主题复查

复查范围为普通浅色、深色、独立浅色毛玻璃。依据2026-10-26设计正文的颜色职责、分类跨页一致性、文字层级、紧凑布局和Android安全区，结合0.4.0两份复查报告；不将示意图当作需要逐像素复制的iOS页面。

## 已修正的偏差

1. 账单列表/日历和分类管理的分段选择器沿用了默认紫灰选中态。改为主题主蓝填充、对应高对比前景；未选项保留中性表面。次级tonal按钮也统一使用主蓝系容器。
2. 分类快捷按钮默认把全部分类名称染成操作蓝。改为中性正文色，分类图标继续显示身份色，选中仍有蓝框和独立蓝色勾选。
3. 深色中账单图标按40%提亮，选择页与报告按28%，管理和统计部分仍为原始色。现在共同使用identityColor的28%明度适配；浅色和毛玻璃保留原色，子类继承根类。颜色编辑器仍存原始ARGB，不把显示提亮值写回数据。
4. 毛玻璃卡片精简外阴影，继续保留模糊、透明浅色表面与细边框，减少叠层边缘干扰。

没有改变收入红、支出绿、零值中性、日均参考主蓝、分类原始色板或财务数据结构。毛玻璃依然是独立浅色主题，不与深色偏好叠加成第三种深色混合主题。

## 验证方式

- 新增7项针对实际控件渲染和跨页颜色的回归，包含深色编辑分类后原始色值不改变。
- 完整Flutter回归280项、Node项目检查20项通过；最后的勾选/阴影调整另跑主题与页面过渡19项通过。最终静态检查无问题。
- 使用独立API36模拟器、SYNTHETIC账本检查首页、记账、账单、日历/选日、周报/排行、周期、统计及分类管理。截图与逐页索引随Release证据包提供，不上传真实账本或设计包里的原版私人截图。
- Vulkan模拟器在补拍时曾退出；补验改用不启用Vulkan的只读实例和推荐ADB端口。模拟器/图形后端与物理手机不同，不声称已完成OEM、完整TalkBack或所有设备GPU验收。

发布沿用0.4.1+12与原升级签名；首次公开0.4.1以Release资产及SHA256SUMS为准。源码经独立PR和CI集成，不直接推送main。

三主题各11个页面（共33张）的最终运行截图已核对。毛玻璃在软件图形模拟器截图中仍可见少量细线；移除外阴影未完全消除，未确定是模糊合成、图形后端还是设备实现差异，不将其写作已修复或已在物理手机复现。配色、文字、选中标记和跨页分类身份色已通过实际控件回归。
