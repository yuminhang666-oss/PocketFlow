# PocketFlow 0.4.1 设计复查修正

基线为 2026-10-27 实际读取的远程 main `ccdbc965798d6133f662fa5e3a7ba7cf1f1296a8`（0.4.0+11）。主控独立分支 `codex/v041-control-polish`，本轮版本 0.4.1+12。参考用户提供的评分对照、Codex/Claude Code 两份复查报告及 2026-10-26 UI 设计正文和七张示意图。报告是问题线索，原设计正文和用户后续要求决定实现，不把报告中的分数或未经设备验证的风险当作实际结果。

## 主要变化

- 账单页重排为列表/日历切换、集中月份卡、收支摘要、当前范围笔数与净收支、按日分组记录。默认收起搜索和筛选，通过右上角入口展开；保留备注/分类搜索、收支、日期、分类及金额筛选、逐项移除和清除。收起时仍显示已激活的条件，列表与日历共享同一过滤结果。历史月补充“查看月份”和回到本月，月份箭头与选择器统一放在月份卡。
- 同日账单共用分组卡片和分隔线；紧凑记录行保留完整金额，长备注在列表省略、详情可读全文。净收支依然是收入减支出，金额按正负及零值使用语义色，不表示账户余额。
- 日历正常字号的日格由至少 88dp 缩短为至少 48dp；大字体随比例增高。嵌入账单时复用上方月份卡。点选日期后滚动至当天明细，保留双收支、今天、未来状态、补记与主动零支出；零支出资格仍依据完整快照。
- 记账分类区前置“全部 N 个分类”入口，不需要输入关键词即可选择任意根类和子类；子类位于快捷网格之前，金额键盘与保存能力保留。窄屏保留稳定的一行快捷类，完整入口不依赖滚动到网格末尾。
- 首页压缩日均主卡、收入/今日支出卡、目标摘要及四宫格间距；多目标显示数量，保留真实金额、进度、增加入口和独立登记说明。延续用户 0.4.0 要求：没有目标时隐藏整块目标区。
- 预算设为零且无支出显示“本月预算为0”；有预算且刚好耗尽仍显示“预算已用完”。
- 报告使用两项主指标加净收支摘要、较短趋势图和排行/回顾定位入口，内容顺序与钻取保留。报告和统计分类占比使用整数分比例，并按一位小数显示；例如 80000/85190 为 93.9%。原有两位小数百分比调用保持默认行为。
- 周期待办明确分为逾期待处理、本期到期、未来七天和已处理，保留跨月逾期展开与实际日期确认等原业务能力。
- 更新应用内离线版本说明，补齐简体、繁体、英文资源。

## 分类名称的验收口径

复查报告混合引用了两套现存目录。通用目录 `catalog_upgrade.dart` 已使用设计名称；旧学生目录 `category_catalog.dart` 及用户自定义目录必须保留其 ID 和名称。0.4.1 不为迎合截图自动改名、归档或重写历史分类。

| 设计/通用目录 | 稳定根 ID | 旧学生目录对应名称 | 默认颜色 |
| --- | --- | --- | --- |
| 学习成长 | study | 学习 | #7A64BB |
| 学习成长相关旧分支 | research | 科研与课程（独立旧根） | #7A64BB |
| 工作支出 | work | 旧目录未含同名根 | #596DB0 |
| 工作支出相关旧分支 | tutoring | 家教成本（独立旧根） | #596DB0 |
| 旅行 | travel | 旅行出行 | #3B9094 |
| 生活费 | income_family | 生活费 | #338574 |
| 工资薪酬 | income_work | 实习兼职 | #327BCB |
| 兼职劳务 | income_labor | 旧目录无同 ID 根；income_tutoring 为家教收入 | #596DB0 |
| 利息收益 | income_interest | 利息 | #348C9D |

对照时以实际分类 ID、根子关系和自定义颜色为准。上述“相关旧分支”是色板/语义对照，不是自动迁移或合并映射。其余设计分类色沿用 0.4.0 单一映射。

## 兼容与授权边界

合同 v3.2.0、数据库 schema4、JSON3/recovery3、依赖及锁保持；不更改金额算法、历史发生日期、分类关联或计划事务。沿用 `cn.pocketflow` 与已有升级签名。生产入口不注入演示账本；设备截图使用显式 SYNTHETIC 测试数据。

本轮先完成本地可审阅源码、安装包和验证记录。尚未提交、推送、合并或发布 GitHub；0.4.0 的发布记录不代表 0.4.1 已发布。实际测试与设备证据见 [QA 记录](qa-v0.4.1.md)。
