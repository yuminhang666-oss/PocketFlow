# Android 个人试用验收清单

先用少量测试账单验收，再记录日常消费。Debug版本与正式发布版分开；本轮未配置正式发布签名。

## 安装

1. 将交付的 `PocketFlow-debug.apk` 传到自己的Android手机，使用文件管理器打开。
2. 如系统询问，允许当前文件管理器“安装未知应用”；安装完成后可关闭此来源授权。
3. 打开PocketFlow，确认首页无预置账单且默认分类可选择。卸载/清理应用数据会移除本地账本，操作前先保存JSON备份。

## 逐项检查

- [ ] 设置当前月预算1500元，首页显示预算1500、支出0。
- [ ] 新增餐饮30元：支出30、余额1470；日额度应为 `floor(147000 ÷ 含今天的剩余天数) ÷ 100` 元。10月17日应为98.00元。
- [ ] 再记20元，支出50、余额1450；首页和统计一致。
- [ ] 打开30元账单，修改为35元并改备注；支出55、余额1445。
- [ ] 删除20元账单，确认后支出35、余额1465；取消删除时账单保留。
- [ ] 查看分类环图、每日柱图、余额曲线，点击读数并切换历史月份。
- [ ] 从系统最近任务关闭APP，再打开，预算、账单及备注仍在。也可在系统设置中强制停止后再打开复查。
- [ ] 设置较小预算造成超支：负余额/超支金额保留，每日建议额度为0；恢复预算后正确重算。
- [ ] 导出Markdown：在文件管理器中打开，预算、总额、分类、每日和逐笔记录一致，中文备注正常。
- [ ] 用系统分享将月报交给自己选择的应用，确认接收方可以读取文件；取消分享不丢数据。
- [ ] 保存JSON备份，再新增一笔测试账单；恢复刚才的备份，确认预检条数及“全量替换”提示，新加测试账单应消失。
- [ ] 选择错误文件/取消恢复：原账本不变。恢复完成后记录显示的本地恢复点ID。
- [ ] 检查小屏、大字体、深色主题、软键盘和系统返回，保存按钮均可操作。
- [ ] 断开网络后，预算、记账、明细和图表正常使用。

发现问题时记录操作步骤、手机型号/Android版本与截图；分享前遮住真实账单和备注。月份、闰年及月末数学边界已由自动测试覆盖，设备试用不要求修改手机系统时间。
