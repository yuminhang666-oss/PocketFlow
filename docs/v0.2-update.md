# PocketFlow 0.2.0 更新与验证

本次依据用户的实际手机截图和上一轮使用评估更新；代码位于 integration/v0.2-experience，基于 main 8b224deabadf042ee901e2bfdf5deaa1d97e2c51。版本 0.2.0+3，合同候选 2.0.0、数据库 3、JSON 备份 2。合并前不是公共 main 基线。

## 已实现

- 中性浅灰/白底与靛蓝主色，替换深绿色大色块；浅色、深色、跟随系统持久化。
- 总览、账单、统计、我的四个目的地；底部中间“记账”按钮占独立空间，不覆盖账单金额。
- 紧凑预算卡，分别显示本月支出、收入、今天支出；无预算、超支、历史与未来月份各有明确口径。
- 支出/收入录入、修改、删除；常用分类、分组细分类搜索、备注、日期、保存并继续、常用模板。
- 16 个支出组、8 个收入组及细分类；加入科研课程、家教成本、数字服务、校园生活及收入场景，均可选择，不代表用户实际已发生消费。
- 分类新增、改名、归档、恢复显示及一级排序；保留旧分类 ID 和历史。
- 账单按日分组，按备注/分类、类型、日期与金额筛选，并显示筛选后收支合计。
- 支出/收入/预算三类统计，排行、稳定分类颜色、带金额轴的全月趋势，以及日期/分类到明细跳转。
- 日历区分“尚未记录”和用户主动确认的零支出。
- 手动储蓄目标、可选轻触反馈；目标登记独立于账本预算。
- 新备份包含目标、模板、主题等个人设置；继续读取 v1；恢复点继续兼容旧编码。

## 财务口径

收入不抵扣支出，不增加月预算；净收支是收入减支出，不是账户余额。每日参考由剩余预算和剩余天数计算。金额使用整数分，未来实际数据为空。目标金额不自动扣除预算。没有加入退款/报销/借贷/转账和自动重复记账的未定义口径。

## 自动验证

直接 Dart 静态分析用于规避本机 Flutter LSP 在中文工作目录中的字节长度错误；这是实际分析结果，不以构建替代分析。完整命令、次数及日志位于本次本地交付目录；最终结果见交付说明。

测试覆盖整数金额、预算边界、SQLite 约束、收入与预算独立、筛选和合计、分类归档/层级、v1/v2 备份与恢复失败回滚、旧恢复点读取、schema 1/2 到 3、主题/目标/模板重启，以及 320×568、360×640、390×844、412×915 和字体 1.0/1.3/2.0 的编辑器布局。

Android Gradle 在 Windows 拒绝中文项目路径，实际构建使用 D 盘已有工具缓存内的隔离 ASCII 副本；保存逐文件 SHA256 输入清单，源码仍位于本次独立 clone。没有安装新依赖、修改全局配置或换签名。

## 兼容与范围

- 包名 cn.pocketflow、原测试签名与数据库路径保留，可覆盖安装已有 0.1.x 测试版。
- 新增个人设置和分类元数据，不改写已有账单金额、日期、备注和审计字段。
- v1 备份没有目标/模板/主题，完整恢复 v1 时这些新数据恢复默认；恢复前界面会明确提示并保留本地恢复点。
- 全程使用虚构测试账本；实际用户账单没有复制到仓库或上传。
- 仍为 Debug 个人测试版。真实手机/OEM、TalkBack 和分享接收方的差异不能由模拟器结果替代。
