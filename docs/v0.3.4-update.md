## 行为与边界

普通记账仍是“记账 → 输入金额 → 保存”。连续保存每次只清空已写入的金额与备注，保留分类与发生日期；撤销使用既有 `PlanningPort.undoCreate(expected)`，没有更换为无条件删除。上一笔的撤销计时不因输入下一笔而延长，离开页面不重新弹出旧保存提示。保存失败保留草稿，不自动重试财务写入。

详情编辑取消回原详情，保存回更新后的详情，再返回来源列表。日期或分类变化时说明来源仍保留原筛选，跨月移动由原仓库重新聚合。统计分类/日期下钻保持独立路由，顶部月份、日期与分类条件明确范围。保留原 IndexedStack，不重建整套导航状态管理。

快捷分类依目录顺序稳定排列，不按频率或金额自动重排；默认最近分类与快捷子类入口保留。完整分类只在独立面板纵向滚动，搜索无结果有明确提示。普通字体下金额键盘与保存入口固定；小屏和2倍字体允许整页滚动至操作区。用户真实常用分类是否均覆盖快捷区仍需手机验收反馈。

主控跨模块范围：A 的入口/页面/语言呈现、主控 composition/版本配置及 D 的测试和本轮测量工具。财务合同 v3.1、整数分、预算/统计算法、数据库 schema4、JSON3/recovery3、包名与原签名均不变；无新依赖，无依赖安装，无新密钥。
