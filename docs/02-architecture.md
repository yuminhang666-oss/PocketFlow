# 架构与数据口径

## 技术选择

沿用用户指定的 Flutter + Dart / Material 3 / Riverpod / Drift SQLite / fl_chart。现在只引入首页基础与数据库需要的依赖；图表、文件选择和分享在对应阶段加入。选择精简功能分目录，界面 → Riverpod 状态 → Repository → Drift；领域层单独维护 Money、CalendarMonth、LedgerEntry、BudgetCalculator，不依赖 UI 或数据库。

[Flutter 架构指南](https://docs.flutter.dev/app-architecture/guide)建议区分界面与数据层；[Drift 查询流](https://drift.simonbinder.eu/dart_api/streams/)用于在表发生变化后更新显示。金额在数据库、聚合、导出中始终为整数分，只在传给图表坐标时转换成 double。

版本为 2026-10-17 pub.dev 元数据候选：flutter_riverpod 3.4.3、drift 2.35.2、drift_flutter 0.3.1、drift_dev 2.35.1、build_runner 2.17.1。最小 Dart 约束 3.12；实际 pub get 和构建尚未执行。Drift 当前原生推荐不再额外手动添加 sqlite3_flutter_libs，见[官方平台说明](https://drift.simonbinder.eu/platforms/)。

## 数据模型 v1

| 表 | 字段 | 约束与用途 |
| --- | --- | --- |
| categories | id、name、sort_order、is_archived | 八个稳定分类 ID；不用中文名称作外键；有历史记录时只归档 |
| monthly_budgets | month、amount_fen、updated_at_utc_ms | YYYY-MM 主键；金额 ≥0；不存在表示未设置，0 表示明确零预算 |
| ledger_entries | id、amount_fen、kind、occurred_local、occurred_at_utc_ms、category_id、note、created_at_utc_ms、updated_at_utc_ms | 金额 >0；kind 预留 expense/income；本地日期参与月份归属；UTC 时间用于排序/追溯 |

表名和字段详见 `lib/core/database/schema.sql`（可执行设计原型）及 `tables.dart`（Drift 模型）。正式迁移将由 Drift 导出 schema 并验证；当前两份结构尚未做生成一致性校验。账单索引为本地日期 + UTC 时间；分类外键启用。货币固定人民币，不加入汇率、自动结转或账户余额。

交易的消费日期由用户选择并保留为本地日历日期，不因后来改变手机时区而迁移月份。时间戳使用 UTC 毫秒。跨日提醒以设备当前本地日期为准，默认中国使用场景。首版不开放未来日期支出；领域统计会排除当日之后的记录，防止未来计划当成已消费。

## 预算计算

选择当月时，累计支出为该月月初到今天（含今天）所有 expense 的整数分之和；income 预留字段，不自动增加预算。剩余 = 月预算 − 累计支出。剩余天数 = 当月天数 − 今天的日号 + 1。每天建议额度 = max(剩余, 0) 整除 剩余天数；不足一分的余数保留在余额，后续每天重新计算。

示例：2026-10-17，预算 150000 分、已支出 60000 分、余额 90000 分，剩余 15 天，每天 6000 分（¥60.00）。支出 1 分后余额 89999 分，每天 5999 分（¥59.99），不用四舍五入抬高可用额度。

- 超支：保留负余额，单独显示“已超支 ¥…”；每天建议额度显示 ¥0.00，避免用负数鼓励继续消费。
- 未设置预算：仍可记账、看总支出；额度为“待设置”，不能把未知预算当成 0。
- 显式零预算：剩余为 0 或负数；进度百分比不计算，显示文案。
- 历史月份：统计整月，显示结余/超支，不显示“今天每天可花”。
- 未来月份：可规划月预算，剩余天数为该月总天数，额度名称为“计划日均”，支出不计为已发生。
- 修改/删除/跨月移动账单：从原始记录重新聚合，刷新受影响月份；不持久化易失真的累计字段。
- 跨午夜/前台恢复：更新时钟 Provider，刷新月份与分母，不等下一次记账。

预算进度原值可超过 100%；绘制进度条时截断到 [0,1]，旁边保留真实超支文案。时间进度与额度进度分开；不以消费“节省”为价值判断。

## 后续图表与导出共用快照

一个月报快照同时含预算、截止日期、逐日金额、分类金额及明细，图表和 Markdown 读取同一份结果。当前月快照截止今天，历史月截止月末；未来月只显示规划。分类百分比可因显示舍入不精确加总至 100%，导出注明规则，不修改原金额。

预算曲线比较每日结束时余额；理论线 = 月预算 − 月预算 × 当日序号 / 当月天数（整数分取下界），明确标记是均匀消费参考而非预测。当前月未来日期的实际曲线留空，不能用零支出伪装成已观测数据。

Markdown：UTF-8、范围/截止日期、金额口径、逐日与分类及逐笔表；转义备注中的竖线和换行。JSON：appId、formatVersion、exportedAt、currency、全部预算/分类/账单；导出分单位，不导出浮点金额。恢复先校验版本、类型、金额范围、日期、重复 ID、外键，预览数量；整体事务写入，错误回滚，并在替换前备份。未知更高版本拒绝恢复；迁移按已支持版本逐步执行。恢复行为会在第四阶段实现，当前未实现。
