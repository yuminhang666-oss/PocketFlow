# PocketFlow 0.2：收支与记账体验更新

旧版首页的大色块、悬浮新增按钮和窄屏输入布局影响日常记账；收入只有数据类型，没有可用录入流程。此次替换为浅色靛蓝主题、独立底部记账入口和固定数字键盘，加入完整收入CRUD与个人使用场景分类。

范围：共享合同与入口装配、UI、Drift迁移及业务、报表/备份、测试/构建校验。由主控在独立integration分支统一适配。基线8b224deabadf042ee901e2bfdf5deaa1d97e2c51；合同候选2.0.0、schema3、备份2；合并前不构成公共接口基线。审阅先检查共享合同及迁移，再检查下游实现。

- 16支出组、8收入组、63细分类，保留原分类ID；分类管理、账单搜索/筛选、分类和每日统计、日历、独立目标、常用模板及持久化主题。
- 金额仍为整数分；收入与目标不自动改变月预算，收支差额不称账户余额。

- 69项Flutter测试、18项Node参考/SQL测试、Dart合同场景和静态分析通过。Android36实际覆盖升级、收入CRUD、模板、目标、主题重启、SAF保存与恢复、离线和小屏1.0/1.3/2.0字体验收。
