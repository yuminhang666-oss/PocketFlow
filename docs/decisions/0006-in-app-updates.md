# ADR 0006：手动版本检查与覆盖更新

日期：2026-10-18。主控集成，版本0.2.1+4。公共main仍为8b224de；本分支叠加于PR #6候选081d6b4，PR以该候选分支为基线，不宣称其已合并。

用户要求保留应用内手动检查和下载入口；此前是主动卸载0.1.1，并非报告安装失败。已再次核验已发布0.1.1与0.2.0的包名cn.pocketflow、相同签名证书及递增versionCode 2→3；没有证据表明覆盖安装失败。

更新端口与共享DTO分别位于lib/contracts/app_update_port.dart、lib/core/domain/app_update.dart。负责人统一接线，涉及A页面、D原生平台与验证；不变更财务接口、schema3和JSON2，不增加依赖。

只在“我的→检查更新”主动查询公开GitHub Releases，包括测试版。启动及回到前台不联网检查，也不显示首页提醒。版本必须同时匹配发布标签、递增versionCode、应用ID、现有签名证书、APK大小和服务器SHA256。更新信息使用每次发布附带的PocketFlow-update.json；缺失或无效元数据不能宣称已是最新版。

只联网GET版本数据，不上传账单，不含账号、遥测或后台通知。失败保留离线记账，更新页提供重试和公开下载页入口；没有后台任务或自动检查偏好，不混入财务备份。

下载按钮打开固定GitHub仓库的HTTPS APK链接，由浏览器下载、Android系统确认覆盖安装；无需REQUEST_INSTALL_PACKAGES或新增依赖。原生桥限制URL目标。系统最终校验真实APK签名；版本元数据校验不替代系统签名校验。

保持包名、测试签名、数据库位置与递增版本号。0.1.1和0.2.0没有版本检查代码，无法远程补入提醒，必须先覆盖安装一次0.2.1，以后才可在应用内手动检查并下载新版本。禁止要求用户先卸载。

0.3规划：分类预算、周期账单与收入提醒、每周回顾、记账反馈；用户不需要快捷记账，本次不扩展这四项实现。
