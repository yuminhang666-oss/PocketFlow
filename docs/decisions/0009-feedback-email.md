# ADR0009：用户将反馈改为邮箱

2026-10-20，用户最新明确指令：“那发送到邮箱吧，邮箱地址：yuminhang666@gmail.com”。该要求覆盖执行方案原第8节的私有GitHub库/服务器/真实Issue回执完成条件；其余0.3范围和验收保持。

采用手机邮件客户端：填写白名单表单 → 预览收件人/主题/正文 → 用户确认打开系统邮件客户端 → 用户在邮件客户端完成发送。App不自动SMTP、不嵌入邮箱密码/应用密码/写入令牌，不部署接收服务，不要求自购服务器或域名。ACTION_SENDTO/mailto限定邮件处理器，Android查询声明仅mailto，无安装/通知/联系人或邮箱读取权限。平台依据：[Android邮件Intent](https://developer.android.com/guide/components/intents-common#Email)。

唯一固定收件人为 yuminhang666@gmail.com。主题是受控类型文本，正文只包含用户表单、随机反馈编号与自愿附带的App版本/build/API；无账本、日志、附件、设备ID。URI中的主题与正文按UTF-8编码，原生端再次限定收件人与长度，不接受任意分享目标或附件。

新增FeedbackMailPort.openComposer返回bool，仅表示邮件编辑器已打开，不能表示发送或送达。持久mailOpened同样不是回执；页面明确投递状态未知。没有邮件客户端时保留本地草稿并提供复制邮箱/主题/正文入口。取消预览不打开外部应用，防忙碌重复打开，草稿仍不随财务恢复删除。

原Node/私有GitHub服务代码与测试保留为本轮历史备选，不由生产装配调用，也不成为0.3部署前提。原FeedbackPort/Receipt状态仅保留本地候选兼容，不用于邮件成功判断。没有创建私有库/App、云资源或真实Issue；无需继续服务器/域名问题。不能因本更改自行发一封测试邮件，真实邮件须用户在客户端确认。
