# ADR 0004：Android 插件打包与测试更新签名

日期：2026-10-17。用户反馈0.1.0账本不能读取、预算不能保存、统计持续加载，并明确要求修复与覆盖更新。

实际旧APK缺少原生插件图所引入的注册类/JNI库；在Android平台生成后重新解析锁定依赖修复。共享模型、数据库版本、存储目录和数据合同无需改变。

主控将Android平台存在性、原生插件图、注册类和逐ABI动态库纳入交付门禁；仅Flutter分析、Windows SQLite测试和APK编译成功不构成设备验收。必须对实际APK进行Android首启、保存、重启及覆盖安装检查。

测试版本延续最初cn.pocketflow包名与签名，私钥移出缓存放入本地独立signing目录，同时保留原副本，不上传私钥。仓库仅记录公开证书指纹；构建缺少原签名文件时明确失败，禁止静默重新生成。versionCode由1提升至2，公开下载前核验证书、版本与ABI依赖。

正式Release签名策略仍单独处理，不能用本次Debug测试签名代替正式发布。实际故障复现、修复、模拟器结果和更新包哈希见 [0.1.1修复报告](../hotfix-0.1.1.md)。
