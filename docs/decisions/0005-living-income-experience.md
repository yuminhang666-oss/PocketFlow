# ADR 0005：0.2 收支与体验更新（本地集成候选）

用户在2026-10-17明确要求根据本次修改建议更新应用。此次由主控在独立检出与integration/v0.2-experience分支完成跨模块集成；当前公共main仍是8b224de，本文和新接口在合并前不是其他对话的公共基线。按ownership将变更分为共享合同、A页面、B存储业务、C统计备份、D验证；提交/推送/合并及公开发布遵守用户授权边界。

合同候选2.0.0：保留支出API，增加收入CRUD、分类管理和个人规划数据；增加接口方法会影响旧实现者，因此明确提升主要合同版本。Category增加可空kind/parentId，null kind保留历史兼容。原8类ID不变；默认提供16个支出组、8个收入组及细分类。历史income不因类别归属而被重写。

数据库3：在2上只增加分类元数据列和personal_state表；金额、账单、预算及数据库路径保持原映射。1直接迁移3保留旧严格校验和事务回滚。新安装与升级添加推荐分类，不覆盖已有名称或归档状态。完整替换备份后不暗中合并分类，用户可以在分类管理中明确补全推荐分类。

备份2：写出kind/parentId和typed profile；读取1时保留记录并使用默认profile，读取2严格校验；更高版本拒绝。恢复点编码2继续读取旧编码1。恢复在同一事务归档账本与profile后全量替换，失败回滚。目标、模板、主题及明确零消费标记一并备份。

收入不抵扣支出，不自动增加预算；收支差额不是账户余额。小目标是独立登记进度，完全不参与预算。退款/报销/借贷/账户互转没有足够的既定模型，本次不伪装为普通收入功能。

UI采用已评审A配色；共享新增入口放在底部操作区域，编辑器独立并固定键盘/保存，分类更多项用分组选择器。日历区分未记账与主动确认零消费。所有新增存储和统计须通过自动测试与Android覆盖升级验收后才能交付APK。无新增依赖、账号、自动上传或付费AI。
