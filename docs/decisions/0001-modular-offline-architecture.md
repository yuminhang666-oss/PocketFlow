# ADR-0001 · 独立精简项目与统一接口

日期：2026-10-17。状态：采用。负责人：主控。

上下文：四个独立 Work 对话开发同一 Android 记账应用，不能共享聊天状态；参考应用范围偏大且金额模型不满足整数分要求。

决策：独立 Flutter 项目；Material 3、Riverpod、Drift、后续 fl_chart；纯 Dart 共享模型与受控接口；GitHub main 唯一公共基线；每模块独立分支与PR，主控集成。C 经 B 的公开快照/恢复端口访问数据，不读取内部数据库表。

取舍：需要维护共享合同和适配层，但避免每个对话自行定义金额、日期与备份结构。首版不用服务端、账号、汇率、付费AI或自动云同步。不能在编译验证前宣称工程稳定。

变更规则：新增共用类型、接口、依赖或修改数据口径，先由主控形成后续 ADR 与 contract PR，合并后再并行适配。
