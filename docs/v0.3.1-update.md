## 更新计划

1. 保存提示：`SnackBar` 显式 `persist:false`、3秒，替换当前提示防止排队。原因是当前 Flutter 的带 action 提示默认持久显示，原来的5秒配置实际不生效。3秒内撤销仍调用原有原子条件删除，已修改/关联周期计划的账目仍拒绝撤销。
2. 应用内更新：手动检查官方 GitHub Releases；API 网络、超时或限流失败时读取同仓库 `releases/latest/download` 的 v2/v1 清单。元数据不合法不能绕过 API 校验；备用入口也验证字段、签名和包名。页面区分网络、超时、限流、元数据、下载/包校验和安装错误，并可重试。
3. 原生下载：用户点击后才下载，显示进度、阻止重复下载、支持取消。流式写入私有缓存，限制大小、连接/读取/整体时间、HTTPS 与受控 GitHub 重定向域名。下载完验证大小、SHA256、APK真实包名、版本名/号和真实签名与当前已安装包一致。安装前再次验证；失败不打开安装器。无存储权限、无账本上传。
4. 系统安装：首次打开本应用的“允许安装应用”设置，用户授权并返回后点击安装；使用既有 FileProvider 的独立 updates 缓存目录，只授予该 APK 读取权限。打开安装器不等于安装成功，取消可重试，不声称静默更新。
5. 毛玻璃主题：按用户最新要求，新增独立的“我的 → 主题 → 毛玻璃（浅色）”，选择后固定浅色，不跟随系统深色。保留原有跟随系统/浅色/深色三个选项。系统能力实现背景模糊、半透明卡片、细高光边框与圆角浮动底栏；金额、报表和列表文字保持实色。高对比度下不模糊并提高填充不透明度。无第三方着色器和外部字体。
6. 语言切换（新增计划，未实现）：在“我的 → 使用偏好 → 语言”提供“简体中文 / 繁體中文 / English”，默认简体中文；切换后即时生效、跨重启保存，与主题相互独立。覆盖主导航、记账、账单、统计、预算/周期计划、恢复备份、更新、反馈及关于页的界面文案与错误提示，并配置对应系统日期选择器等组件。英文适配长按钮、小屏及大字体；繁体中文人工核对用词。内置分类按稳定ID及原始名称本地化，用户改名、备注、目标和模板名称保持原文。语言只改变呈现，货币仍为人民币，整数分金额和日期归属不变；JSON字段/版本保持稳定。采用Flutter标准本地化资源，不采用运行时自动翻译或网络翻译。新增locale字段与备份兼容策略在实现时纳入合同审核。

## 合同扩展

`PersonalProfile.surfaceStyle` 可选字段 classic/glass，旧存档缺省 classic；默认 classic 不额外写字段。`theme` 仍仅 system/light/dark，避免旧客户端的枚举崩溃；旧客户端可读新备份但忽略新增外观字段，财务数据仍兼容。`savePreferences` 增加可选 surfaceStyle，profile原子读改写及普通编辑保留该字段。本次为合同3.1.0候选扩展，不把未合并代码称为共享基线。

新增独立可选 `AppPackageUpdatePort`，保留旧 AppUpdatePort 与打开发布页能力。新能力仅用于平台下载、进度、取消和安装交接。原财务合同与网络隔离。

## 验收与限制

- 实际保存后2秒仍有撤销，3秒开始退出；不点撤销只隐藏提示、不删除账目，点撤销只删除本次记录。
- 更新测试覆盖API限流/超时备用入口、损坏信息与异签名、重试清空旧候选、下载取消/校验失败不安装、首次安装授权及重试不重新下载。
- 主题测试覆盖切换、profile重新读取、JSON往返与恢复；原明暗设置为浅色或深色时选择毛玻璃均固定浅色，高对比度禁用模糊。
- 内存增量为工程估算：以1080×2376 RGBA缓冲计算，单全屏约9.8MiB；只对卡片和底栏取样约占屏幕一半，每层约4—5MiB，多层缓冲和缓存估计增加15—35MB，高分辨率或切页瞬时预算30—60MB。该范围不是测量结果或保证上限。模拟器驱动/进程不稳定，未完成有效的普通浅色/毛玻璃成对PSS测量；失败样本的0值无效，不能当作0开销。Flutter官方亦说明背景模糊较昂贵，参见[BackdropFilter](https://api.flutter.dev/flutter/widgets/BackdropFilter-class.html)。真机需用同页同数据对照复测。
- 真实手机当时的失败原因不能仅凭截图确定。备用入口可避开 API 限流或部分域名故障；若手机无法访问整个 GitHub 下载网络，仍需显示网络错误，不能保证所有网络可达。
- 已安装0.2.1/0.3.0没有本次新代码，无法远程改变其更新行为；首次获取0.3.1仍受旧版能力限制。此后由新版本内的更新器处理后续版本。
- 具体通过数、APK摘要、设备与尚未验证项目以本任务的本地 QA 报告为准；不沿用0.3.0历史结果。
