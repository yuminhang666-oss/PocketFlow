# 0.3.1 图标更新包（内部构建 7）

2026-10-20，用户提供蓝白毛玻璃钱包原图，明确要求随 0.3.1 更新应用图标。基线为已发布 0.3.1+6、PR #10 合并后的 main `900f3c7a52841662e0cb074bf442d9fca93e7f4c`。主控独立分支 `integration/v031-icon` 整合 Android 资源、设计源文件及版本号，经 PR/CI 交付。

## 变更

- 原样保存用户图片为 `design/app-icon/source.png`，SHA256 `c7f424cf06dce1feebd2092d9c35e4e64aca8e9429c90c510c3f90030c247127`；仅确定性缩放和 Android 资源装配，无生成式重绘。
- Android 24–25 使用五档 48/72/96/144/192px 传统图标；Android 26+ 使用系统自适应遮罩。钱包图案保持整体，适配圆形与圆角方形桌面。清单补充 `roundIcon`，不强制所有桌面使用同一外形。
- 显示版本仍为 0.3.1，内部构建号由 6 增至 7；包名、签名、数据库、业务及 Flutter 页面保持原样。设计原图不作为运行时 Flutter 资产打包；APK 只包含缩放后的 Android 图标。
- 不覆盖原 `v0.3.1` tag 或其已发布资产；新包使用 `v0.3.1-release` tag，作为最新 Release，保留历史可追溯性。源码 ZIP、v1/v2 更新清单、同字节兼容 APK 与摘要均需对应本次构建。

## 验证与边界

本轮实际静态检查、Flutter 完整测试、Node 检查、Release APK/签名/原生库检查、Android API36 桌面和覆盖安装的结果及摘要记录在交付目录 `deliverables/v0.3.1-icon/qa-report.md` 与 `evidence/`。只有实际完成的项才能写入报告。测试账本仅使用隔离模拟器虚构数据。

旧 0.3.1+6 客户端按显示版本筛选更新，不会把同名 0.3.1 的内部构建 7 提示为新版，因此已安装构建 6 的用户需从新 Release 下载后直接覆盖安装一次。更早版本仍可发现 0.3.1；网络不可访问 GitHub 时仍会受限。未验证用户真机/OEM 桌面缓存、全部形状及主题图标、完整 TalkBack、帧率或内存。本次不增加此类承诺。
