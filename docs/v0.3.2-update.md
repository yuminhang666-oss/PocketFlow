# 0.3.2 优化更新

2026-10-21。基线为实际远程 main / v0.3.1-release 的 `4eb9be53bc5b2c9088a4ce16cea2949176983dba`，旧包 0.3.1+7，新包 0.3.2+8。独立分支 `integration/v032-control-polish`。用户完成本地审阅后追加要求提交、推送并提供手机应用内更新；主控按 PR/CI 集成和 Release 发布流程执行，实际结果以远程记录为准。

## 原因与修复

| 修复前 | 修复后 | 原因与依据 |
| --- | --- | --- |
| 玻璃背景位于 Navigator 外；Android 原生过渡在其上铺 colorScheme.surface | 仅玻璃主题的 PredictiveBack fallbackColor 透明 | 锁定 SDK 的 PredictiveBackPageTransitionsBuilder 委托 FadeForwardsPageTransitionsBuilder；后者的实色过渡背景遮住了玻璃底图。未修复代码的像素回归在第一个 16ms 采样失败：应为 [236,243,247,255]，实际 [248,252,255,255]。 |
| 月份快照尚未到达时从 null profile 取默认外观 | 保留最近一次已确定的呈现偏好 | 外观不再跟随暂时加载的财务快照回退；不缓存、代替或拼接财务数据。新月份等待回归验证主题和语言仍保持。 |
| 颜色动画与玻璃主题扩展、背景结构同步时序不同 | 根主题一次性应用 | 新偏好写入后立即打开路由也继承同一外观，不延迟页面、加遮罩或延长动画。 |
| 钱包整图画布居中，但主体偏右下，传统/自适应装配比例不同 | 统一光学锚点、缩放和背景延展 | 图片含外沿及阴影，钱包并不在透明前景层。用人工审阅锚点 (662,655) 对齐 108dp 图层中心 (54,54)，主体包围宽 50dp。传统图标使用同一变换的中央 72dp 视窗。 |

保留 Android 原生预测返回及默认过渡路径、Material 3 弹层与键盘行为；系统减少动画时不进行页面位移动画。独立玻璃始终浅色，高对比度仍禁用玻璃模糊。分类子项增加选中勾，不依赖颜色作为唯一反馈；数字输入没有新增动效或等待。

实际 320dp / 2 倍字体检查还发现英文三行保存文字挤到默认胶囊轮廓；将记账页“保存并继续”统一为主保存按钮的 16dp 圆角，并把多行保存文字居中。修复后重新完整验证和构建，最终包实际重跑九种主题/语言组合。

使用锁定 Flutter 3.47.7 / Dart 3.13.5；恢复现有锁定缓存后独立生成、静态检查和 181 项 Flutter 测试通过，包含新增 12 项主题回归。Node SQL / 协作 / 历史反馈测试分别 9 / 3 / 8 项通过；历史服务不是当前应用的生产反馈流。

本轮录像、Android 桌面截图、模拟遮罩、设备矩阵、摘要及限制，以工作区 `deliverables/v0.3.2/qa-report.md` 和其 evidence 为准。没有物理手机/OEM 验收；不得把可变帧率录像当作每次刷新都已采样，或把模拟器合成器指标当作真机 Flutter 帧率。源设计图、旧包和原工作树均保留。

## 应用内更新发布

显示版本由 0.3.1 提升至 0.3.2，使旧版按语义版本发现更新；包名与证书不变。发布资产同时提供 `PocketFlow-update-v2.json` 与 `PocketFlow-update.json`。正式 `PocketFlow-0.3.2-release.apk` 和兼容旧 v1 清单的 `PocketFlow-0.3.2-debug.apk` 为同一 Release 构建的相同字节，后者仅保留旧文件名，不是 Debug 构建。两份清单必须匹配安装包大小、SHA256、证书、versionCode 8。系统确认安装及必要的“允许此来源安装”仍遵循 Android 行为。
