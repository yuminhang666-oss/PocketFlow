# PocketFlow 应用图标（0.3.2）

`source.png` 为用户 2026-10-20 提供并指定用于本应用的蓝白钱包原图，原样保存。未重新生成或重绘图案；不据此宣称拥有第三方素材的版权。

运行 `pwsh -File tools/generate-launcher-icons.ps1` 生成 Android 24–25 的五档传统图标及 Android 26+ 的自适应图标底图。只进行确定性的尺寸转换和安全区装配，不新增依赖。

自适应图标使用 108dp 图层，钱包整图仍装配在背景层，前景透明；`roundIcon` 指向同一资源。原图仅为设计源文件，不作为 Flutter 运行时资产打包。

0.3.2 按钱包主体（约 x=300..1022、y=268..987）检查视觉重心，采用人工审阅的光学锚点 (662,655)，而非原图画布中心 (627,627)。这不是自动像素质心测量。脚本将光学锚点映射到 (54dp,54dp)，钱包外包围宽度设为 50dp；原图内侧背景向外延展，排除白色外沿及重复圆角框。钱包形状、光影与颜色由原图确定，不进行生成式重绘。

Android 24–25 五档资源使用同一坐标变换的中央 72dp 视窗，并只应用一次圆角方形轮廓。26+ 不预制圆角，由系统遮罩裁切。脚本验证原图仍为 1254px 方图；更换原图须重新审阅锚点。圆形/圆角方形模拟预览不等于 OEM 实机验收；实际检查与限制见本轮 QA 报告。

参考：[Android adaptive icons](https://developer.android.com/develop/ui/views/launch/icon_design_adaptive)。真实设备验证及限制见 `docs/v0.3.1-icon-update.md`。
