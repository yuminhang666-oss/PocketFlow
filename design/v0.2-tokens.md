# 0.2 视觉规则

主色 #3E63DD，页面 #F9F9FB，卡片 #FFFFFF，浅蓝强调区 #EDF2FE，正文 #1C2024，辅助文字 #60646C。来源参考 Radix Colors 的 Indigo/Gray 系列，项目采用本地常量，无外部资产依赖：[Radix Colors](https://github.com/radix-ui/colors)。

深色采用中性背景 #11131B、表面 #1C202A、浅靛蓝 #ADBFFF，避免大面积深绿。分类颜色由稳定 root ID 映射；同时显示图标、文字和正负号，颜色不是唯一含义。错误/超支采用 error 语义色。

预算主数字 36sp，次级金额 20sp；金额不省略为省略号。正文 14/16sp，区块标题 18sp。普通触控至少48dp，卡片圆角14–22dp；上下留白压缩以保证常用信息先出现。

底栏使用 Scaffold.bottomNavigationBar 和 SafeArea，占据独立区域；列表不能延伸到新增按钮背后。编辑页上部可滚动，数字键盘及保存区域固定；横屏极小高度使用整页滚动兜底。

大字体下卡片从三列逐步变为两列/一列，分类网格减少列数，日历根据实际字宽扩大可滚动宽度和格高，保持数字完整。禁止通过统一关闭系统字体缩放掩盖布局问题。
